ZeroOmega WG установлен

Локальный помощник запущен. Осталось один раз добавить расширение в браузер. После этого импорт и подключение доступны в настройках ZeroOmega WG.

Google Chrome

  1. Откройте chrome://extensions и включите «Режим разработчика».
  2. Нажмите «Загрузить распакованное расширение» и выберите установленную папку:
    {{CHROME_PATH}}
  3. Отключите исходный ZeroOmega, чтобы прокси управляло одно расширение.
  4. Откройте настройки ZeroOmega WG → «Новый профиль» → WireGuard / AmneziaWG. Импортируйте .conf и нажмите «Применить изменения».
  5. В auto switch выберите созданный профиль для нужных доменов, а профиль по умолчанию — «Напрямую».

Установщик можно удалить или переслать. Папку установленного приложения оставьте на месте.

Firefox

В папке firefox установлен неподписанный XPI. Для постоянного использования в обычном Firefox нужна подпись Mozilla, которую можно получить без публикации в каталоге. Для разработки доступна временная загрузка через about:debugging.

ZeroOmega WG is installed

The companion is running. Add the browser extension once:

  1. Open chrome://extensions and enable Developer mode.
  2. Select Load unpacked and choose {{CHROME_PATH}}.
  3. Disable the original ZeroOmega. Create a WireGuard / AmneziaWG profile, import your .conf, then apply changes.
  4. Use auto switch rules for selected domains; keep Direct as the default.

You may delete or share the downloaded installer. Keep the installed application directory. Firefox requires a Mozilla-signed XPI for permanent installation; this kit contains an unsigned XPI.
